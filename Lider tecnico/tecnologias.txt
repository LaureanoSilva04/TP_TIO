=== Propuesta de Tecnologías a Incorporar - Proyecto Panadería ===

Para mejorar la escalabilidad, el rendimiento y la experiencia de usuario de la aplicación web, el Líder Técnico propone evaluar la incorporación de las siguientes tecnologías en las próximas etapas del desarrollo:

1. Frontend y Diseño Avanzado:
   - Tailwind CSS: Para acelerar el desarrollo de la interfaz de usuario mediante clases utilitarias, asegurando un diseño moderno, limpio y completamente responsive.
   - Next.js: Framework de React para implementar renderizado del lado del servidor (SSR), lo cual optimizará drásticamente la velocidad de carga del catálogo y el SEO en buscadores.

2. Backend, Base de Datos y Persistencia:
   - Docker: Para contenedorizar el entorno de desarrollo local (servidor y base de datos relacional). Esto garantizará que todo el equipo trabaje exactamente bajo la misma configuración, evitando el clásico "en mi máquina funciona".
   - PostgreSQL: Como motor de base de datos relacional principal, para aprovechar su robustez en el manejo de transacciones complejas y soporte nativo para datos tipo JSON (ideal para el detalle de los pedidos).
   - Redis: Para implementar una capa de caché en memoria que almacene el catálogo de productos más consultados, reduciendo las consultas repetitivas a la base de datos principal.

3. Servicios de Terceros e Infraestructura:
   - Firebase Authentication: Para delegar de forma segura el registro e inicio de sesión de los clientes, permitiendo la autenticación rápida con cuentas de Google.
   - GitHub Actions: Herramienta de CI/CD para automatizar la ejecución de las pruebas que diseñe el equipo de QA cada vez que se intente realizar una fusión (merge) en la rama principal.
